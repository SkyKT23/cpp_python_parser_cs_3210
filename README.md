# cpp_python_parser_cs_3210

A python parser built using C++ to correct the text of a python program, and output the text of the python program in a .txt file. Project was completed for CS 3210 at MSU Denver in March 2024.

Authors: Robert Beer, Illan Gibson, Skylar Gurnett, Nicole Train
Date: 11 March 2024

Known issues:
As of 2026, this parser will fix some of the incorrect formatting in a .py file, but it does not fix all of them, as indicated by the output final_output.txt file. In particular, the implementation of correcting block indentation does not work properly. Attempts were made to fix this with the assistance of Microsoft Copilot, but were only partially successful.

For the future:
Revisiting the errors of this code is intended by Skylar Gurnett, owner of this repository and one of the co-authors of this program. Writing and implementing unit tests is part of this plan.
